# GTX-A 개통 전후 광역버스 승차건수 변화와 GTX역행 연계버스 이용 분석

GTX-A 북부 구간의 운정중앙·킨텍스·대곡역 권역을 대상으로, 개통 전후 광역버스 **승차건수 변화**와 지역·교통 특성의 관련성을 분석한다. GTX역으로 향하는 마을·시내버스 이용도 함께 분석하여 역 접근·환승 여건을 살펴본다.

> **현재 연구 방향 · 2026-10-26**
>
> - 주 분석: GTX-A 250m 격자 126개의 **건수 기준 7변수 OLS**.
> - 추가 분석: 2025년 **GTX역행 마을·시내버스 승차건수 OLS**, 광역버스 변화량과의 **Spearman 순위상관**.
> - 인터뷰·현장답사: 정량 결과를 접근·환승 여건과 연결해 해석하는 보조자료.
> - GTX-C: 개통 전 접근·연계 여건을 지도화하는 **적용 예시를 준비하는 단계**. 수요 예측 결과가 아니다.
> - 기존 Ridge·Logistic·쌍대비교 순위모형 등은 과거 탐색 실험이다. 현재 최종 예측모형으로 채택하지 않는다.

## 연구 질문과 범위

1. GTX-A 개통 전후 광역버스 승차건수는 어디에서 얼마나 변화했는가?
2. GTX역 보행시간·경쟁 목적지·인구·토지이용 등은 변화량과 어떤 관련이 있는가?
3. 개통 후 어떤 특성의 격자에서 GTX역행 마을·시내버스 이용이 많은가?
4. 광역버스 변화량과 GTX역행 연계버스 이용은 공간적으로 함께 나타나는가?

관찰자료의 **조건부 관련성·공간적 패턴**을 분석한다. 개별 승객의 GTX 전환이나 GTX 개통의 인과효과를 직접 식별하는 연구는 아니다.

### 이용인원 합계에서 승차건수로 바꾼 이유

2024-10-17 자료의 `utztn_nope`는 1~4에 거의 균등하게 분포하고 평균 약 2.505인 반면, 2025-11-06은 대부분 1이며 평균 약 1.013이다. 날짜별 합성 값 생성 방식의 차이로 **이용인원 합계 비교에서 감소가 과대하게 나타나는 문제**가 확인되어 행 수 기준으로 재집계했다.

승차건수 역시 합성자료의 기록 수이므로 실제 승객 수와 동일하다고 단정하지 않는다. 건수 기준 전환이 합성자료의 표본 포함 비율·생성오차 문제까지 해결하는 것은 아니다. 2025-10-16 자료를 현재 비교일과 혼용하지 않는다.

경쟁 목적지 비율과 버스 통행시간도 교통카드 기반 변수이므로 **건수 기준으로 함께 재계산**했다. 이용인원 기준 결과는 비교용으로 보존한다.

### 공급구조 유지의 의미

[전처리 코드](code/02_preprocessing/gtx_a/09_새데이터_공급구조유지_250m격자.py)에서 격자별 두 날짜의 노선번호 집합과 노선별 정류장 구성을 비교한다. 정류장 대응에는 이름을 우선 활용하며 좌표 차이 100m 이내를 허용한다.

이는 **승차기록에서 관측된 노선·정류장 구성**의 유지다. 실제 모든 운행노선·정류장을 완전하게 관측했다거나 배차간격·운행횟수까지 동일하다는 뜻은 아니다. 마을·시내버스의 공급구조 유지 여부는 별도로 다룬다.

## 1. 광역버스 변화량: 최종 7변수 OLS

종속변수는 격자별 **2025년 승차건수 − 2024년 승차건수**다. 126개 전체, 상수항, HC3 강건 표준오차를 사용한다. 상호작용이나 역 더미를 포함하지 않는다.

$$
\Delta B_i = \beta_0 + \beta_1\ln(1+Walk_i) + \beta_2 Pop_{20\text{–}50,i} + \beta_3\ln(1+Floor_i) + \beta_4 Residential_i + \beta_5 Competing_i + \beta_6 BusTime_i + \beta_7 ICDistance_i + \varepsilon_i
$$

| 변수 | 정의·단위 | 계수 | HC3 p-value |
|---|---|---:|---:|
| log(1+GTX역 보행시간) | 보행시간(분)의 자연로그 변환 | 26.5864 | **.0074** |
| 20~50대 인구 | 2024년 인구(명), 원 단위 | .0123 | .2901 |
| log(1+건축물 연면적) | 2024년 연면적(천㎡)의 자연로그 변환 | −7.7984 | .2794 |
| 주거지역 비율 | % | .1958 | .3159 |
| GTX 경쟁 목적지 비율 | 2024년 하차좌표 확인 건수 중 연신내·서울역 반경 1km 하차 비율(%) | −.2495 | **.0425** |
| 평균 버스 통행시간 | 2024년 유효 통행시간(0분 초과·240분 이하)의 건수 기준 평균(분) | −.2332 | .2958 |
| IC 도로거리 | km | −1.1545 | .2446 |

**R² .2633 · 수정 R² .2196 · 모형 HC3 F 검정 p=.0077 · n=126**

다른 변수가 같을 때 보행시간이 길수록 변화량이 높고, 경쟁 목적지 비율이 높을수록 변화량이 낮은 관계가 나타났다. ‘변화량이 높다’는 덜 감소하거나 더 증가하는 방향이며 개통 후 이용건수 자체가 많다는 뜻은 아니다. 인구·연면적·주거지역·버스시간·IC 도로거리는 5% 수준에서 유의하지 않았다.

## 2. GTX역행 마을·시내버스 이용 분석

### 정답값과 분석 범위

종속변수는 **2025년 GTX역행 마을·시내버스 승차건수**다. 126개 격자 안 정류장에서 승차하고 하차 정류장 이름에 운정중앙역·킨텍스역·대곡역이 포함된 기록을 집계한다. 광역버스 24개 노선과 역 정류장 간 통행은 제외한다.

이는 역 방향 접근 통행의 대리지표다. 실제 GTX 승차·환승 여부를 확인한 값은 아니다. 또 권역은 **승차 격자의 소속 권역**이며 도착 GTX역과 혼동하지 않는다.

2025년 집계는 총 **1,015건**(운정중앙 권역 672·킨텍스 113·대곡 230), 2024년은 135건이다. 2024년에 역명 정류장이 없던 경우가 있어 이 차이를 그대로 GTX 전환 증가량으로 해석하지 않는다. 주모형은 변화량이 아닌 **개통 후 이용 수준**을 분석한다.

[011 시각화 노트북](code/03_eda/011_새데이터_승차변화_시각화.ipynb)에서 다음 건수 기준 결과를 확인한다.

- 카카오맵 격자 오버레이: 감소는 붉은색·동일은 회색·증가는 파란색, 감소 TOP 3 노란 테두리.

노트북에는 **기존 이용인원 기준 지도·애니메이션·과거 예측모형 결과도 보존**돼 있다. 셀 제목과 입력 열을 확인하여 건수 기준 결과와 혼용하지 않는다. 카카오맵은 로컬 서버·인터넷·카카오 JavaScript 키 및 등록 도메인이 필요하다. 키를 노트북에 직접 저장하지 않는다.

인터뷰는 광역버스 이용 유지와 GTX 이용의 다양한 배경을 파악하고 연계버스 분석을 확장한 계기로 활용한다. 현장답사는 역 출입구–버스정류장 동선·횡단·대기·환승시설 등을 비교한다. 특히 운정중앙과 대곡의 차이를 설명하되 ‘새 역이면 연계가 좋다’와 같은 일반 법칙이나 시설물의 인과효과로 단정하지 않는다. 현재 답사 결과와 과거 비교일 당시 여건도 구분한다.

## 4. GTX-C 적용 예시 — 계획 단계

현재 논문의 중심은 GTX-A 분석이다. GTX-C 북부 의정부·덕정 주변은 다음 **개통 전 현황 진단 지도**의 적용 예시로 검토하고 있다. 지도 작성과 공통 변수 정의는 아직 완료된 것으로 제시하지 않는다.

1. 개통 전 광역버스 승차 정류장이 있는 250m 격자 선정. A의 개통 전후 공급구조 유지 조건과 다름을 명시.
2. GTX역 보행시간·경쟁 목적지 비율·현재 역 예정지 방향 연계노선 유무 구축.
3. 요인별 지도를 제시하고 A의 관측 범위와 비교. 범위 안이라는 이유로 지역 이전의 타당성이 입증되는 것은 아님.
4. 접근·연계 여건의 검토 지점을 제안. 점수·격자별 예상 감소건수·전환확률은 산출하지 않음.

C 경쟁 목적지는 A의 서울역·연신내 기준과 개념적으로 대응하도록 정의해야 한다. 기존 연계노선이 개통 후에도 유지된다고 가정하지 않는다. 낮은 이용량을 곧 공급 부족으로 해석하지 않는다.

기존 [노선·교통카드 수집 코드](code/01_collection/gtx_bc/)와 [정류장 매칭 코드](code/02_preprocessing/gtx_bc/), [가공자료](data/processed/gtx_bc/)는 보존한다. B·C의 수요 예측·시뮬레이션은 후속 연구 과제다.

## 과거 실험과 주요 한계

이전 이용인원 기준 OLS, Poisson·NB2, Ridge, 이진분류, 쌍대비교 순위학습, 상대 변화율 예측은 연구 진행 이력으로 남긴다. **종속변수·집계 기준·비교일이 다른 성능 수치를 현재 결과와 혼합하지 않는다.** 현재는 B·C에 적용할 검증된 최종 예측모형을 확보했다고 주장하지 않는다.

- 두 날짜의 합성자료를 비교하므로 일별 변동·연도별 수집 포함 비율·합성 생성 방식의 영향을 받을 수 있다.
- 세 역 권역뿐이며 통제집단·개인 추적자료가 없어 GTX 개통의 인과효과와 실제 이용자 전환을 식별하기 어렵다.
- 절대 변화량은 기존 승차규모와 관련될 수 있다. 영향력 격자·baseline 조정·함수형태·공간적 의존성을 함께 점검하고 통계적 유의성만으로 결론 내리지 않는다.
- 마을·시내버스는 역명 정류장 하차 기준의 접근 통행 대리지표이며 2024년 역명·노선·정류장 변화의 영향을 받을 수 있다.
- 순위상관은 다른 조건을 통제한 분석이 아니다. 개통 전 규모와 공간적 공통요인의 영향을 배제하지 못한다.
- 주모형과 탐색·보조분석을 구분한다. 유의한 변수나 높은 수정 R²만 골라 최종 결과로 제시하지 않는다.
- C의 현황 지도는 A의 관계가 C에서 재현됨을 입증하지 않는다.

원자료(`data/raw/`), `.env`, archive, 참고·발표자료 등은 `.gitignore`에 따라 Git에 포함하지 않는다. **따라서 저장소를 clone하는 것만으로 원자료 기반 전체 수집·전처리를 재현할 수는 없다.** API 키를 코드·노트북·결과물에 기록하지 않는다.
