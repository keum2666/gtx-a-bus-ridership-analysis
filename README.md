# GTX-A 개통 전후 광역버스 승차 변화 분석

GTX-A 북부 구간의 **운정중앙역·킨텍스역·대곡역 권역**에서 서울행 광역버스 승차가 어떻게 달라졌는지 분석한다. 지역·교통 특성과 승차 변화의 관계를 회귀분석으로 살펴보고, 같은 분석 공간에서 개통 후 GTX역으로 향하는 마을·시내버스 이용을 연결한다.

## 현재 연구 방향

**2026-11-08 기준**, 하루 전체를 중심으로 원고를 정리하고 있다. 논문의 최종 수록 범위는 다음 네 가지 대안을 놓고 검토 중이다.

| 대안 | 시간대 | 분석 구성 |
|---|---|---|
| 1 | 하루 전체 | 광역버스 회귀분석 + 순위상관분석 |
| 2 | 하루 전체 | 대안 1 + 연계버스 승차 유무에 따른 맨휘트니 검정 |
| 3 | 출근시간대 | 광역버스 회귀분석 + 순위상관분석 |
| 4 | 출근시간대 | 대안 3 + 연계버스 승차 유무에 따른 맨휘트니 검정 |

모든 대안에 광역버스 승차 변화와 GTX역 방향 버스 이용 기초통계를 포함한다. 출근시간대는 **06:00 이상 10:00 미만**이다. 시간대와 맨휘트니 수록 여부는 아직 확정하지 않았다.

- **광역버스 회귀분석:** 승차 변화와 관련된 지역·교통 특성 확인.
- **순위상관분석:** 광역버스 변화량과 개통 후 GTX역 방향 버스 이용량의 관계 확인.
- **맨휘트니 검정:** 연계버스 승차가 관측된 격자와 관측되지 않은 격자의 광역버스 변화량 분포 비교.
- **현장답사·인터뷰:** 접근·환승 여건과 이용자의 선택 배경을 이해하는 자료.

**연계버스 회귀분석은 현재 원고 본문에서 제외**한다. 연계버스 이용 자체의 발생 요인은 별도 질문이며, 두 회귀분석을 각각 수행하는 것만으로 두 지표의 관계를 확인할 수 없기 때문이다. 기존 코드·결과는 보존한다. GTX-B·C 수요 예측과 과거 머신러닝 실험은 현재 논문의 최종 분석에 포함하지 않는다.

## 데이터와 집계 기준

| 항목 | 기준 |
|---|---|
| 자료 | 국토교통부 지역별 교통카드이용 합성데이터 |
| 비교일 | 개통 전 2024-10-17 / 개통 후 2025-11-06 |
| 대상 통행 | 파주·고양에서 승차하여 서울에서 하차한 광역버스 통행 |
| 공간 단위 | 250m 격자 |
| 표본 | 운정중앙 63개, 킨텍스 26개, 대곡 37개, 총 126개 |
| 표본 선정 | 두 비교일의 관측 광역버스 노선·정류장 구성이 유지된 격자 |
| 승차건수 | 교통카드 기록의 행 수. `utztn_nope`를 합산하지 않음 |
| 광역버스 변화량 | 2025년 승차건수 − 2024년 승차건수 |

연도별 `utztn_nope` 분포가 달라 이용인원 합계를 그대로 비교하기 어려워 승차건수로 재집계했다. 합성자료의 기록 수이므로 실제 승객 수와 동일하게 해석하지 않는다. 공급구조 유지는 **기록에서 관측된 노선·정류장 구성의 유지**이며, 배차간격·운행횟수가 같다는 의미는 아니다.

하루 전체 광역버스 회귀는 126개, 출근시간대 회귀는 개통 전 출근 승차기록이 있는 113개 격자를 사용한다. 기초통계와 순위상관은 각 시간대 모두 126개 전체를 사용한다. 동일한 113개 격자로 두 시간대를 비교한 별도 결과도 보존한다.

## 현재 결과

아래 연계버스 수치는 **기존 정류장 집계 기준**이다. 집계 범위를 정리한 뒤 최종 논문 수치를 확정해야 한다.

### 하루 전체 광역버스 승차 변화

| 권역 | 격자 수 | 2024년(건) | 2025년(건) | 변화량(건) | 변화율 |
|---|---:|---:|---:|---:|---:|
| 운정중앙 | 63 | 2,568 | 1,896 | −672 | −26.2% |
| 킨텍스 | 26 | 3,492 | 2,617 | −875 | −25.1% |
| 대곡 | 37 | 1,050 | 1,004 | −46 | −4.4% |
| 전체 | 126 | 7,110 | 5,517 | −1,593 | −22.4% |

감소 76개, 유지 15개, 증가 35개다. 변화량 −40건 이하 격자는 운정중앙 6개·킨텍스 5개로 총 11개다. 출근시간대에는 대곡역 권역의 합계가 8.9% 증가하여 하루 전체와 변화 방향이 달랐다.

### 광역버스 회귀분석

격자별 승차 변화량을 종속변수로 사용하고, 상수항과 7개 독립변수를 포함한 OLS에 HC3 강건 표준오차를 적용한다.

| 독립변수 | 정의·변환 |
|---|---|
| GTX역 보행시간 | log(1 + 보행시간(분)) |
| 20~50대 인구 | 명 |
| 건축물 연면적 | log(1 + 연면적(천㎡)) |
| 주거지역 비율 | % |
| GTX 경쟁 목적지 비율 | 개통 전 하차좌표 확인 기록 중 서울역·연신내역 반경 1km 내 하차 비율(%) |
| 평균 버스 통행시간 | 개통 전 유효 기록의 평균(분) |
| IC 도로거리 | 최근접 IC까지 도로거리(km) |

하루 전체 모형은 **R²=0.2633, 수정 R²=0.2196, 모형 p=0.0077, n=126**이다. 보행시간 계수는 +26.5864(p=0.0074), 목적지 비율 계수는 −0.2495(p=0.0425)로 유의했다. 나머지 독립변수는 5% 수준에서 유의하지 않았다.

다른 독립변수를 함께 고려했을 때 GTX역 보행시간이 짧고 서울역·연신내역 주변 하차 비율이 높은 지역에서 변화량이 낮은 관계를 보였다. **변화량이 낮다는 것은 감소폭이 크거나 증가폭이 작다는 뜻**이다. 로그 보행시간 계수를 1분 증가 효과로 해석하지 않는다.

### GTX역 방향 버스 이용과 순위상관

| 승차 격자의 권역 | 전체 격자 | 승차 관측 격자 | 0건 격자 | 승차건수 |
|---|---:|---:|---:|---:|
| 운정중앙 | 63 | 21 | 42 | 672 |
| 킨텍스 | 26 | 9 | 17 | 113 |
| 대곡 | 37 | 13 | 24 | 230 |
| 전체 | 126 | 43 | 83 | 1,015 |

권역은 **승차 격자의 최근접 GTX역** 기준이며 실제 하차한 GTX역별 집계와 다르다. 두 기준의 노선 수·승차건수를 섞지 않는다.

| 하루 전체 순위상관 | n | Spearman ρ | p-value |
|---|---:|---:|---:|
| 전체 | 126 | −0.359 | <.001 |
| 운정중앙 | 63 | −0.410 | .001 |
| 킨텍스 | 26 | −0.314 | .118 |
| 대곡 | 37 | −0.488 | .002 |

0건 격자도 포함한다. 비교 대상은 **광역버스 개통 전후 변화량과 연계버스 개통 후 이용 수준**이며, 연계버스 변화량이 아니다. 지터는 화면 표시 위치에만 적용하고 통계는 원래 값으로 계산한다.

### 맨휘트니 검정: 수록 검토 중

연계버스 승차 0건 집단과 1건 이상 집단의 광역버스 변화량을 양측 검정으로 비교한다. 동순위·연속성 보정을 적용한 점근 p값이다.

| 범위 | 0건 / 1건 이상 격자 | U: 0건 집단을 먼저 입력 | p-value |
|---|---:|---:|---:|
| 전체 | 83 / 43 | 2,522.5 | <.001 |
| 운정중앙 | 42 / 21 | 643.0 | .003 |
| 킨텍스 | 17 / 9 | 105.5 | .124 |
| 대곡 | 24 / 13 | 244.0 | .005 |

전체 중앙값은 각각 −1건과 −11건이다. 중앙값은 분포를 설명하는 값이며 검정 대상을 중앙값 차이만으로 한정하지 않는다. 전체 격자 쌍에서 승차 관측 집단의 변화량이 더 낮은 비율은 동률을 절반 반영하면 약 70.7%다. 이는 이용자의 GTX 전환율이 아니다.

[통계·그림 모듈](code/03_eda/plot_spearman_group_comparison_options.py)의 `calculate_stats()`는 **1건 이상 집단을 먼저 입력**하므로 전체 U가 1,046.5로 반환된다. 위 표와 합하면 `83 × 43 = 3,569`이며 양측 p값은 같다. 모듈에는 권역별 Holm 보정 p값도 별도로 있다. 위 표는 보정 전 p값이다.

순위상관은 두 지표의 순서 관계를, 맨휘트니는 승차 유무에 따른 집단 차이를 본다. 같은 자료를 사용하므로 독립된 GTX 전환 검증으로 취급하지 않는다.

## 연계버스 집계에서 확인할 사항

현재 집계는 선정된 광역버스 정류장 ID에서 출발한 기록을 사용한다. **격자 안 모든 마을·시내버스 정류장의 공간 합계와 다를 수 있다.** 0건은 현재 집계 범위에서 기록이 없다는 뜻이다.

- **새암공원:** 같은 격자의 다른 정류장에서 운정중앙역행 2건이 확인되었으나 현재 출발 정류장 ID 집계에는 포함되지 않는다.
- **한울마을2단지:** 약 69m 떨어진 같은 이름의 다른 정류장에서 99건이 확인되었다. 그 정류장은 해당 격자 밖이므로 같은 격자의 값에 바로 더하지 않는다.
- **하차 정류장 이름:** 이름에 대곡역이 들어간 아파트 정류장 2곳의 26건이 기존 1,015건에 포함된다. 이를 제외한 989건은 비교 결과이며 현재 기준을 대체하지 않는다.

주변 지역 전체에 이용이 없었다거나 실제 GTX 이용을 확인했다는 의미는 아니다. 출발 격자·정류장과 실제 역 접근 하차 정류장의 범위를 정리한 뒤 최종 집계·검정 결과를 다시 확인해야 한다.

## 해석 범위와 보존 자료

- 두 기준일의 합성자료를 사용하므로 일별 변동과 합성 생성 방식의 영향을 받을 수 있다.
- 회귀는 다른 독립변수를 고려한 관련성, 순위상관·맨휘트니는 통제하지 않은 관계·집단 차이를 보여준다. 개통의 인과효과와 개인별 교통수단 전환을 직접 확인한 결과는 아니다.
- 절대 변화량은 개통 전 이용 규모와 관련될 수 있다. 공간 의존과 영향력 관측치도 검토할 필요가 있다.
- 대곡역 방향 버스 이용에는 기존 3호선·경의중앙선·서해선 접근 목적이 포함될 수 있다.
- 인터뷰와 답사는 배경을 이해하는 자료이며 환승센터 자체의 효과를 검증하지 않는다.
- 하루 전체에는 출근시간대가 포함된다. 두 모형의 유의성이 다르다는 것만으로 계수 차이가 유의하다고 주장하지 않는다.

이용인원 기준 OLS, 연계버스 회귀, Poisson·NB2, Ridge·Logistic·순위학습 및 GTX-B·C 수집 코드는 연구 이력으로 보존한다. 기존 문서·결과에는 당시의 방향이 포함되어 있으므로 현재 수록 범위와 구분한다.
